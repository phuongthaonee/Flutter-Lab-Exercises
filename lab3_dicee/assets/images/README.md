# Dice Images Required

Please add 6 dice face images to this folder with the following exact names:

- dice1.png
- dice2.png
- dice3.png
- dice4.png
- dice5.png
- dice6.png

## Where to find dice images:

1. **Search online**: "dice faces PNG flat" or "dice PNG transparent"
2. **Free resources**:
   - flaticon.com
   - freepik.com
   - pngwing.com
   - icons8.com

## Requirements:

- PNG format with transparent background (recommended)
- Square aspect ratio (e.g., 512x512, 256x256)
- Flat or material design style works best
- Each file should show the corresponding number of dots (1-6)

After adding the images, run:
```
flutter pub get
flutter run
```
