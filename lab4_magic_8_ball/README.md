# lab4_magic_8_ball

Mô tả
Ứng dụng quả bóng thần kỳ — nhấn vào bóng để nhận câu trả lời ngẫu nhiên từ 5 kết quả khác nhau. Củng cố và nâng cao hiểu biết về StatefulWidget.

Kiến thức đạt được
- Nguyên tắc "single source of truth": chỉ lưu một biến int ballNumber, từ đó suy ra toàn bộ UI
- Phân biệt lưu state là index (đúng) vs lưu trực tiếp giá trị (sai)
