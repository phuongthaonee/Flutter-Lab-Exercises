# Magic 8 Ball Assets Setup

## Required Assets

You need to create the `assets/images/` folder and add 5 Magic 8 Ball images:

### File Names and Answers:
1. **ball1.png** - "It is certain"
2. **ball2.png** - "Yes definitely"
3. **ball3.png** - "Ask again later"
4. **ball4.png** - "Don't count on it"
5. **ball5.png** - "Very doubtful"

### Steps:
1. Create the folder structure:
   ```
   mkdir -p assets/images
   ```

2. Download or create 5 Magic 8 Ball images with the answers shown above

3. Save them in `assets/images/` with the exact names: ball1.png, ball2.png, ball3.png, ball4.png, ball5.png

### Where to Find Assets:
- Angela Yu Flutter course resources
- Search online for "magic 8 ball PNG"
- Create your own using image editing software

### After Adding Assets:
Run the following command to test the app:
```
flutter run
```

The app will display a Magic 8 Ball that changes to a random answer when tapped!
