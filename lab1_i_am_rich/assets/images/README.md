# Diamond Image

Please download a free diamond PNG image and save it as `diamond.png` in this directory.

Recommended sources:
- https://www.pngall.com/diamond-png/
- https://www.cleanpng.com/free/diamond-shape.html
- https://www.vecteezy.com/free-png/diamond-pattern

Look for a transparent PNG image of a diamond that you like, download it, and rename it to `diamond.png`.

Place it in: `assets/images/diamond.png`
