# Xylophone Audio Assets

Place the following 7 WAV files in this directory:

- note1.wav (C note)
- note2.wav (D note)
- note3.wav (E note)
- note4.wav (F note)
- note5.wav (G note)
- note6.wav (A note)
- note7.wav (B note)

## Where to get the audio files:

1. **Angela Yu Flutter Course**: If you're following the course, download the assets from the course materials.

2. **Free Resources**: Search for "xylophone notes WAV free" or "musical notes WAV free download"

3. **Generate your own**: Use online tone generators to create simple sine wave tones at these frequencies:
   - C4: 261.63 Hz
   - D4: 293.66 Hz
   - E4: 329.63 Hz
   - F4: 349.23 Hz
   - G4: 392.00 Hz
   - A4: 440.00 Hz
   - B4: 493.88 Hz

Make sure all files are in WAV format and named exactly as listed above.
